## SUPERMAEKET SALES ANALYSIS DASHBOARD

# Project Overview
This project analyzes supermarket sales data using Microsoft Excel. The goal is to understand sales performance, product category trends, outlet performance, and product visibility through an interactive dashboard.

# Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Slicers and interactive dashboard
- GitHub

# Dataset
BlinkIT Grocery Data

# Project Objectives
1. Analyze overall sales performance.
2. Compare sales across product categories and outlet types.
3. Analyze Low Fat and Regular product sales.
4. Study the relationship between product visibility and sales.
5. Perform statistical analysis and identify potential outliers.

# Key Performance Indicators
- Total Sales: 1,201,681.49
- Average Sales: 140.99
- Average Product Visibility: 6.61%

# Statistical Analysis
- Average Sales
- Median Sales
- Minimum and Maximum Sales
- Standard Deviation
- Variance
- Quartiles and Interquartile Range (IQR)
- Outlier analysis

# Dashboard Features
- Sales by Product Category
- Top 4 Categories vs Remaining Categories
- Sales by Outlet Type
- Low Fat vs Regular Sales
- Product Visibility vs Sales
- Product Category Contribution by Outlet Type
- Average Sales by Product Category and Outlet
- Interactive Outlet Type filter

# Conclusion
The project provides an overview of supermarket sales performance and helps identify trends across product categories and outlets using Excel visualizations and statistical analysis.
